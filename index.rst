Otterus2D Documentation
=======================

Welcome to the official documentation for the **Otterus2D** game engine.

Otterus2D is a 2D game engine built with C++20, modern OpenGL 4.5 Core, Box2D physics, EnTT Entity Component System (ECS), and Lua scripting via Sol3.
