Tutorials Overview
==================

Welcome to the Otterus2D tutorial series! These practical guides take you step-by-step through creating games and systems using the Otterus2D engine.

Available Tutorials
-------------------

* :doc:`getting_started`:
  Learn how to set up ``assets/scripts/main.lua``, configure ``AssetManager``, instantiate an entity in the registry, attach ``Transform`` and ``Sprite`` components, handle keyboard input, and trigger audio effects.

Next Steps
~~~~~~~~~~

Once you complete the getting started guide:

* Explore :doc:`../how-to/handle_collisions` to implement physics and triggers.
* Check out :doc:`../how-to/play_audio_sfx` for audio playback and multi-channel sound management.
* Refer to the :doc:`../reference/lua_api` for the complete API reference.
